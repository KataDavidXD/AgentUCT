# uct_engine

`uct_engine` is the backend-agnostic implementation of agent-uct: reuse-aware
Upper Confidence Trees for discrete, compositional workflow optimization.

The canonical method description, quick start, integration contract, scope,
and test commands are in [`../README.md`](../README.md).

This package contains:

- public state, batch, evaluator, scoring, and result contracts;
- the prefix-search tree and raw-reward statistics;
- reuse-aware cluster- and item-level marginal-cost models;
- the search loop, budget handling, and iteration records;
- a self-contained RAG-shaped mock example and deterministic tests.

Models, prompts, datasets, persistence, workflow replay, and experiment
analysis belong to the integrating application rather than this algorithm
core.
